Ask AI Extension - Test Page

Testing Instructions

  1. Install the Ask AI Extension in Chrome
  2. Configure your OpenAI API key in the extension options
  3. Right-click in any text field below
  4. Select "Ask AI to..." from the context menu
  5. Test the context-aware features by making multiple requests
  6. Right-click anywhere and select "Clear AI conversation history" to reset

Test 1: Basic Text Input

Try asking: "Write a greeting" then follow up with "Make it more formal"

Test 2: Textarea with Context

Try asking: "Summarize this page" - The AI should understand the page context

Test 3: Conversation History

Test multi-turn conversation:

  1. Ask: "What is React?"
  2. Then ask: "What are its main features?" (should reference previous answer)
  3. Then ask: "How does it compare to Vue?" (should maintain context)

Features to Validate

  • ✓ Conversation history persists across multiple requests in the same tab
  • ✓ Page context (URL, title, meta description) is included
  • ✓ Selected text is recognized and included in context
  • ✓ Current field content is considered when available
  • ✓ "Clear AI conversation history" option works
  • ✓ Notification appears when conversation is cleared
  • ✓ AI provides contextually relevant responses
  • ✓ Follow-up questions reference previous messages
